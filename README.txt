DIGITALÍZATE DESKTOP
Requiere Java 17 o superior. Ejecutar Ejecutar.bat o java -jar DigitalizateDesktop.jar.
En IntelliJ o NetBeans abrir pom.xml y ejecutar mx.digilizate.desktop.Desktop.
Datos locales en ~/DigitalizateDesktop/datos.bin. No comparte datos con Android.
Código fuente en src/main/java. Pruebas ejecutables en src/test/java (clase Tests, método main).
Lista enlazada para registros, pila para deshacer, cola para reportes. Merge Sort estable para apellidos; búsqueda lineal para texto parcial y binaria para código exacto sobre copia ordenada.
No incluye autenticación, QR, sincronización, árbol ni tabla hash. Aplicación académica local, no usar para datos sensibles reales.
